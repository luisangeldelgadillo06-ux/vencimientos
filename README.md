# 🛒 Sistema de Control de Vencimientos para Minimarket
**Desarrollador:** Luis Ángel Delgadillo  
**Rol:** Full Stack Developer (Proyecto Personal Autónomo)  
**Contacto:** luisangeldelgadillo06@gmail.com

Este es un proyecto personal **Full Stack** desarrollado de forma autónoma con **Spring Boot**. Su objetivo es gestionar el inventario de un comercio y reducir mermas mediante alertas visuales de expiración en tiempo real.
